Ember & Thyme — Hearth Kitchen: a cozy original cooking game. Orders land on the board, you grill patties, chop vegetables, stack dishes on the plate and serve them before customers walk out — a 3-minute lunch shift in a desktop browser, keyboard and mouse, no network needed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play. Or open `game/index.html` directly in desktop Chrome.
